# Protocolo de recuperação

1. Identifique intenção e entidades.
2. Abra a nota operacional atual.
3. Abra o registro semântico correspondente.
4. Abra o dossiê quando a evolução importar.
5. Execute `eva_memory.py search` ou `context`.
6. Abra inicialmente de três a oito fontes.
7. Para dados exatos, use a fonte original; declare lacunas.

Hierarquia: decisão atual de {{NOME}}; nota operacional atual; memória viva recente; fonte histórica; inferência identificada.
