# Protocolo de escrita

Antes de gravar, mostre `🧠 Eva está salvando uma memória...`.

1. Preserve fontes históricas.
2. Capture a mudança durável com origem auditável (`eva_memory.py capture`).
3. Atualize a nota operacional e o registro semântico pertinentes.
4. Atualize derivados (`eva_memory.py index`).
5. Execute `eva_memory.py audit`.
6. Confirme somente após a verificação.

Sucesso: `✅ Memória salva na {{VAULT}}: <resumo>.`

Falha: `⚠️ Memória não foi salva: <motivo concreto>.`
