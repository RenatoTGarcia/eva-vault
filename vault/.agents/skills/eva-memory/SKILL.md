# Memória da Eva

A {{VAULT}} é a única fonte de verdade persistente. Não crie outra base nem trate memória local da ferramenta como canônica.

## Antes de agir

Confirme a raiz absoluta da vault e leia o `AGENTS.md`. Para recuperação, leia [references/retrieval-protocol.md](references/retrieval-protocol.md). Para captura ou alteração, leia [references/write-protocol.md](references/write-protocol.md) e [references/memory-schema.md](references/memory-schema.md).

Use `scripts/eva_memory.py` para `search`, `context`, `capture`, `index` e `audit`. Use caminhos absolutos. O importador histórico é `scripts/import_eva_csv.py`.

Não salve conversa casual, conteúdo temporário, hipótese não confirmada ou credenciais. Peça confirmação para dados altamente sensíveis ou de terceiros.
